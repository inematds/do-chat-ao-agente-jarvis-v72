Lesson 5 · 15 min

Memory: how it remembers you tomorrow

Memory is the difference between an AI that forgets everything when it restarts and one that has known you for months. In INTELECTO, it’s a database on your computer, with keyword search and no API cost. Understanding how it searches changes how you tell it things.

Start lesson

In this lesson, you will

  1. 1Two layers: MEMORY.md and the memory.db database
  2. 2How keyword search chooses what to remember
  3. 3Categories and deduplication
  4. 4The two-day test

Goal: explain where the assistant saves what you tell it and how it searches, and prove that it remembers on another day, in a new conversation.

01 · From what you tell it to what it remembers

Click each block.

Click each block in the diagram to see what it does.

Layer 1, MEMORY.md: a few fixed facts, always in context. Layer 2, memory.db: grows without a limit, and only what’s relevant to the question is included.

02 · What changes in how you use it

Click each tab.

1. Keyword search

Search looks for the words in your question among your memories. It doesn’t use “embeddings” (meaning-based search), by design: it’s simple, local, and free.

So: tell it facts using the words you’d use to ask about them later.

Best“Every Monday I finish the sales report.” Later: “What do I do every Monday?”

2. Ask it to save

The assistant decides what to save when AGENTS.md tells it to. To avoid relying on that, say: “save this: ...”.

The save_memory, search_memory, and forget_memory tools are available in the conversation.

RequestSave this: my report deadline is Monday at 10 a.m.

3. Forget

Did a fact change? Tell it the new one; if it’s almost the same as the old one, it updates it. If a fact is wrong or you don’t want it saved, ask it to forget.

Everything stays in a file of your own, not on a third-party server.

RequestLook up what you know about the sales report and forget the old time.

4. Didn’t it remember?

First, ask if it saved the information: “What do you know about Monday?” If it didn’t, reinforce the rule in AGENTS.md: save what you learn about me.

If it saved the information but didn’t find it, your question used different words. Try again using the same words.

E4 ruleIf it doesn’t remember, check how memory is saved and adjust it.

03 · The two-day test

Send it in Telegram or the terminal. See how it works with and without memory.

Day 1 · share three facts
Save this: every Monday I finish the sales report.
Save this: I prefer short bullet-point answers.
Save this: my main client is called <NOME DO CLIENTE>.
Day 2 · new conversation, don’t repeat yourself
What do I do every Monday?
How do I prefer my answers?
Who is my main client?
Database search, as the loop does it
SELECT content, category FROM memories_fts
WHERE memories_fts MATCH 'segunda OR relatório OR vendas'
ORDER BY bm25(memories_fts)
LIMIT 5;
Simulation: illustrative example

You (day 2): What do I do every Monday?

Jarvis: You finish the sales report. Want me to make a list of what’s left?

The word segunda found the memory saved on day 1.

You (day 2): What do I do every Monday?

Jarvis: I don’t have that information. Can you tell me?

The fact stayed only in the day 1 conversation history, which disappears when you restart. It never made it into the database: the rule to save it is missing from AGENTS.md, or you didn’t ask it to “save this”.

You (day 2): What’s my weekly task?

Jarvis: I couldn’t find anything about that. Can you tell me?

The fact is in the database, but none of the words in your question appear there (weekly isn’t segunda). Ask again using the words you used: “what do I do every Monday?”

04 · Practice: the memory test

Exercise E4 in sequence 2.

E4 · Memory test

2 days

Day 1: share three facts about yourself using “save this”. On day 2, in a new conversation (after restarting the assistant), ask about them.

Done when: it remembers all three without you repeating them.

E4b · What it knows about you

10 min

Ask what it knows about you. Correct one fact and ask it to forget another.

Done when: the next answer shows the corrected fact and leaves out the forgotten one.
