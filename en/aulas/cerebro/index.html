Lesson 6 · 15 min

The brain: cloud or local, decided with your numbers

The AI model is the easiest part to swap. In the cloud, OpenRouter gives you access to more than a hundred models with one key. On your computer, Ollama runs at no cost per message and sends nothing outside your machine. The choice isn't a matter of taste: it's a table with speed, quality, and cost.

Start lesson

In this lesson, you will

  1. 1What OpenRouter and Ollama do
  2. 2Why changing the brain doesn't change the rest
  3. 3Build the speed × quality × cost table
  4. 4Where the cloud key is stored

Goal: compare one cloud model and one local model using the same question, then decide what to use each for based on your numbers.

02 · How to compare fairly

Click each step.

1. A real question

Choose a question you would actually ask the assistant, preferably one related to a task in your meu-jarvis.md.

Use exactly the same text with both models.

ExampleOrganize these into three priorities: finish the sales report, reply to two clients, and prepare for Thursday’s meeting.

2. Measure the time

Time it from sending until the full response arrives. Run it twice: the first call to the local model is usually slower because it needs to load.

Write down the second time.

Write downTime in seconds, cloud and local.

3. Give it a rating

Read both responses without knowing which is which, if you can ask someone to switch their order. Rate each from 1 to 5: Was it accurate? Did it follow your style? Was it useful?

A short note for each response is enough.

CriterionWould I use this response without rewriting it? Yes = 4 or 5.

4. Check the cost

For the cloud model, check the OpenRouter dashboard to see how much the question cost. Locally, each message costs nothing; the cost is keeping the computer on.

Write your decision in one line: which model for what.

DecisionDaily routine locally; client messages in the cloud.

03 · Configuration and table

The cloud key follows the same rule as the token: only in .env or the vault.

.env · cloud key
OPENROUTER_API_KEY=<paste the key you created at openrouter.ai/keys>
config.json · both providers (from the README)
"providers": {
  "default": "openrouter",
  "openrouter": { "model": "anthropic/claude-sonnet-4-20250514" },
  "ollama": { "model": "llama3.2", "base_url": "http://localhost:11434" }
}
Request to the agent · switch the brain
Switch the default provider to ollama (model llama3.2), keep openrouter as an alternative, and run the tests again. Don’t change anything outside the configuration.

Decision: I’ll use ____ for ____ and ____ for ____.
Simulation: illustrative example
  • Difficult questions, long text, and multi-step reasoning.
  • A computer without enough memory or a graphics card for a good local model.
  • You’re willing to pay for usage and send the text outside your machine.
  • Sensitive data that can’t leave the machine.
  • Many simple messages per day, where usage costs would add up.
  • Working without internet, or as a backup when the cloud goes down.
